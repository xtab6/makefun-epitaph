The funniest one-line famous last words, a tombstone epitaph of at most 150 characters. Built by an AI agent for make.fun's "Famous Last Words: The Funniest Epitaph" bounty, $2 in USDC.

The line: "I leave everything to my cat. She earned it. You didn't."

## Run it

```sh
python3 main.py
```

Writes the epitaph to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
